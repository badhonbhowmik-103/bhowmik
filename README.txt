BADHON BHOWMIK — PERSONAL PORTFOLIO WEBSITE

Files
- index.html: website structure and content
- style.css: responsive styling
- script.js: mobile navigation and current footer year
- assets/: original images extracted from Page.docx

IMPORTANT IMAGE NOTE
All six embedded images were copied directly from the supplied Word document.
The image files were not edited, cropped, recolored, or recompressed.

How to view
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in a browser.
   An internet connection is needed for the optional Google Fonts; the site still works without them.

How to publish with GitHub Pages
1. Create/open your repository.
2. Upload index.html, style.css, script.js and the entire assets folder.
3. Keep the same folder structure and filenames.
4. In repository Settings > Pages, select the branch and root folder, then save.
